## Требования (FURPS+)
| Код    | Требования                                                                                                                                                                       | Комментарий                                                                                                                                |
|--------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------|
| **F**  | **Функциональные (Functionality)**                                                                                                                                               |                                                                                                                                            |
| F1     | Система должна предоставлять новому клиенту на сайте список доступных депозитов с актуальными ставками.                                                                          | Для депозитного направления.                                                                                                               |
| F2     | Система должна позволять новому клиенту на сайте подать заявку на депозит, указав номер телефона и ФИО.                                                                          | После подачи заявки менеджер кол-центра может предложить особые условия.                                                                   |
| F3     | Система должна обеспечивать передачу заявки с сайта в систему кол-центра для просмотра менеджером.                                                                               |                                                                                                                                            |
| F4     | Система должна предоставлять клиенту в интернет-банке список доступных депозитов с актуальными и персонализированными ставками.                                                  |                                                                                                                                            |
| F5     | Система должна позволять клиенту в интернет-банке подать заявку на открытие депозита, указав счёт и сумму.                                                                       |                                                                                                                                            |
| F6     | Система должна подтверждать операцию подачи заявки на депозит в интернет-банке с помощью СМС-кода.                                                                               | Функционал СМС реализован в ядре системы, требует доработки подрядчика, но этого следует избежать; реализовать силами команды банка.       |
| F7     | Система должна обеспечивать работу сотрудников бэк-офиса депозитов и кредитов с данными о ставках, ведущимися в XLS-файлах.                                                      | Возможно, реализовать в АБС.                                                                                                               |
| F8     | Система должна поддерживать процесс согласования ставки по заявке на депозит в АБС.                                                                                              |                                                                                                                                            |
| F9     | Система должна обрабатывать заявку на открытие депозита менеджером бэк-офиса с подтверждением условий в АБС.                                                                     | Этап MVP.                                                                                                                                  |
| F10    | Система должна отправлять клиенту СМС после подтверждения размера ставки и после открытия депозита.                                                                              |                                                                                                                                            |
| F11    | Система должна предоставлять новому клиенту на сайте информацию о кредитном предложении со ставкой; полная информация о возможных условиях хранится в Кредитном конвейере.       | Кредитное направление.                                                                                                                     |
| F12    | Система должна позволять новому клиенту подать заявку на кредит через сайт, указав номер телефона и ФИО.                                                                         |                                                                                                                                            |
| F13    | Система должна при указании клиентом на сайте паспортных данных обеспечивать получение решения об одобрении/неодобрении кредита на основе данных скоринга (общие данные из БКИ). |                                                                                                                                            |
| F14    | Система должна после подачи заявки на кредит через сайт отправлять клиенту СМС о необходимости прийти в отделение для получения кредита и идентификации.                         |                                                                                                                                            |
| F15    | Система должна позволять менеджеру в отделении подать заявку на кредит через АБС                                                                                                 |                                                                                                                                            |
| F16    | Система должна позволять продолжить работу с заявкой, если клиент уже получил предварительное одобрение на сайте                                                                 |                                                                                                                                            |
| F17    | Система должна предоставлять клиенту в интернет-банке список доступных кредитов с актуальными условиями                                                                          |                                                                                                                                            |
| F18    | Система должна при подаче заявки на кредит в интернет-банке повторно проводить скоринг по упрощённой процедуре, если ситуация изменилась.                                        |                                                                                                                                            |
| F19    | Система должна позволять клиенту в интернет-банке подать заявку на кредит, указав счёт зачисления средств и данные для заявки.                                                   |                                                                                                                                            |
| F20    | Система должна подтверждать операцию подачи заявки на кредит в интернет-банке с помощью СМС-кода.                                                                                |                                                                                                                                            |
| F21    | Система должна отправлять клиенту СМС об изменении статуса заявки на кредит.                                                                                                     |                                                                                                                                            |
| F22    | Система должна предоставлять клиенту в интернет-банке предодобренное предложение по кредиту (если по клиенту ранее проводился скоринг и рассчитана приемлемая сумма).            |                                                                                                                                            |
| **U**  | **Удобство использования (Usability)**                                                                                                                                           |                                                                                                                                            |
| U1     | Интерфейс работы клиента (сайт, интернет-банк) должен быть максимально удобным.                                                                                                  |                                                                                                                                            |
| U2     | Отклик по всем операциям должен быть максимально быстрым и занимать миллисекунды.                                                                                                |                                                                                                                                            |
| U3     | При работе пользователи должны видеть привычные цвета и брендированные элементы в соответствии с системой дизайна, принятой в компании.                                          |                                                                                                                                            |
| **R**  | **Надёжность (Reliability)**                                                                                                                                                     |                                                                                                                                            |
| R1     | Доступность интернет-банка и новых сервисов 24/7 в 99,9% случаев.                                                                                                                |                                                                                                                                            |
| R2     | Отказоустойчивость при собоях в ЦОД                                                                                                                                              | Команда интернет-банка утверждает, что пока это невыполнимо; сейчас всё работает в одном ЦОД на одной группе серверов, есть резервный ЦОД. |
| R3     | Необходимо предусмотреть равномерное горизонтальное масштабирование и распределение запросов между серверами, приложениями и ЦОД.                                                | АБС может масштабироваться только вертикально из-за своей БД.                                                                              |
| R4     | Избегать прямой работы интернет-банка с API АБС в новом процессе (из-за перегруженности БД АБС и вероятности отказа)                                                             |                                                                                                                                            |
| **P**  | **Производительность (Performance)**                                                                                                                                             |                                                                                                                                            |
| P1     | Справочные данные при проведении платежей должны загружаться менее чем за секунду (сейчас — больше секунды).                                                                     |                                                                                                                                            |
| P2     | Система должна выдерживать нагрузку от онлайн-подачи заявок на большое количество продуктов.                                                                                     |                                                                                                                                            |
| **S**  | **Поддерживаемость (Supportability)**                                                                                                                                            |                                                                                                                                            |
| S1     | При доработках во всех системах нужно максимально использовать технологии, уже имеющиеся в банке.                                                                                | MS SQL и Oracle                                                                                                                            |
| S2     | Новые технологии должны быть совместимы с существующими платформами разработки, а внутри банка должна быть экспертиза (понимание на уровне языков программирования).             |                                                                                                                                            |
| S3     | Для очередей сообщений предпочтительно использовать Kafka на перспективу.                                                                                                        | Текущая версия платформы интернет-банка несовместима с Kafka.                                                                              |
| S4     | Следует рассмотреть перевод интернет-банка на микросервисную архитектуру в рамках задачи открытия депозитов.                                                                     |                                                                                                                                            |
| S5     | Необходимо предусмотреть разработку документации для дальнейшего расширения системы.                                                                                             |                                                                                                                                            |
| S6     | Реализацию бизнес-функционала СМС-подтверждения в интернет-банке следует выполнить силами команды разработки банка, избегая доработки со стороны подрядчика ядра системы.        |                                                                                                                                            |
| **+R** | **Ограничения (Restrictions)**                                                                                                                                                   |                                                                                                                                            |
| +R1    | Текущая версия платформы интернет-банка несовместима с Kafka.                                                                                                                    |                                                                                                                                            |
| +R2    | АБС может масштабироваться только вертикально из-за ограничений базы данных.                                                                                                     |                                                                                                                                            |
| +R3    | Обмен между базами данных и Кредитным конвейером происходит раз в сутки; ускорить обмен и проводить его чаще невозможно.                                                         | Заявки на кредит по предодобренным предложениям должны обрабатываться в тот же рабочий день.                                               |
| +R4    | Систему кредитного скоринга нельзя нагружать дополнительными процессами по предрасчётам скоринга, так как она испытывает повышенную нагрузку в рабочие часы.                     |                                                                                                                                            |
| +R5    | Идентификация новых клиентов только через посещение Банка.                                                                                                                       |                                                                                                                                            |
| +R6    | С сайта и из интернет-банка передаётся чувствительная информация; данные необходимо защищать с помощью механизма шифрования трафика.                                             |                                                                                                                                            |
| +R7    | Предодобренные кредиты требуют повторного скоринга при подаче заявки  (по упрощённой процедур)                                                                                   |                                                                                                                                            |
